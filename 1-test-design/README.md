## Важное примечание

Данный чек-лист составлен **без доступа к требованиям / спецификации** (так как сайт `saucedemo.com` — это учебный стенд, а не коммерческий проект).

Все проверки основаны на:
- Исследовательском тестировании (изучение поведения системы на месте)
- Стандартных практиках тест-дизайна
- Типовых сценариях для формы авторизации (позитивные, негативные, граничные, UI/UX)

При наличии требований чек-лист мог бы быть скорректирован или дополнен.
